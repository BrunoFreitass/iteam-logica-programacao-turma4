## 📁 Organização do repositório

```
/
├── Aula02/
│   ├── README.md          <- índice da aula
│   ├── Ex01/
│   │   ├── README.md      <- enunciado do exercício
│   │   └── algoritmo.alg  <- sua resposta
│   ├── Ex02/
│   └── ...
│
├── Aula03/ ... Aula06/
│
├── Aula07/
│   └── ProjetoFinal/
│
└── README.md
```

Cada pasta de exercício já vem com um `README.md` contendo o **enunciado**. Você só precisa salvar o seu arquivo de resposta dentro dela.

---

## 📌 Padrão dos arquivos

Salve sua resposta sempre com o nome **`algoritmo.alg`**, dentro da pasta do exercício:

```
Aula03/
└── Ex05/
    ├── README.md
    └── algoritmo.alg
```

Se quiser entregar também o fluxograma ou uma versão em outra linguagem, use `fluxograma.png` e `algoritmo.py` na mesma pasta.

> ⚠️ Evite **espaços** e **acentos** nos nomes dos arquivos.

---

## 🚀 Como entregar os exercícios

Depois de concluir um exercício:

1. Salve o arquivo na pasta correta.
2. Faça o commit.
3. Envie para o GitHub.

```bash
git add .
git commit -m "Aula 03 - Exercicio 05"
git push
```

A correção será realizada diretamente no seu repositório.
