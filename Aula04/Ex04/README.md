# Exercício 04 — Calculadora de Áreas

**Aula 4 — Estruturas de Seleção** · Seleção Múltipla (CASO)

## Enunciado

Leia uma opção para calcular a área:

1. Quadrado — `area = lado * lado`
2. Retângulo — `area = base * altura`
3. Triângulo — `area = (base * altura) / 2`
4. Círculo — `area = PI * raio * raio` (use PI = 3,14)

Caso o usuário informe uma opção diferente de 1, 2, 3 ou 4, exiba: "Opção inválida".
