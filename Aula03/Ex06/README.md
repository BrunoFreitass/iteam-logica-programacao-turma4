# Exercício 06 — Conversor de Temperatura

**Aula 3 — Operadores matemáticos, lógicos e relacionais** · Operadores Aritméticos

## Enunciado

Leia a temperatura em graus Celsius e converta para Fahrenheit.

Fórmula: `F = (C * 9 / 5) + 32`
