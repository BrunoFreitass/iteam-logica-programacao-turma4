# Exercício 16 — Controle de Acesso da Empresa

**Aula 3 — Operadores matemáticos, lógicos e relacionais** · Operadores Lógicos

## Enunciado

Uma empresa possui regras diferentes de acesso:

- Funcionários entram apenas se estiverem identificados **E** possuírem crachá.
- Visitantes entram apenas se estiverem acompanhados **OU** possuírem autorização prévia.

Leia: é funcionário? (V/F), possui crachá? (V/F), está acompanhado? (V/F), possui autorização? (V/F). Informe se o acesso foi permitido.
