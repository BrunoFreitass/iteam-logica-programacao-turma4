# Exercício 05 — Calculando o IMC

**Aula 3 — Operadores matemáticos, lógicos e relacionais** · Operadores Aritméticos

## Enunciado

Receba o peso e a altura e informe o IMC.

Fórmula: `IMC = peso / (altura * altura)`
