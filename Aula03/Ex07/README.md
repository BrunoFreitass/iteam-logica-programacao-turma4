# Exercício 07 — Calculando Descontos

**Aula 3 — Operadores matemáticos, lógicos e relacionais** · Operadores Aritméticos

## Enunciado

Crie um algoritmo que leia o valor de um produto e o percentual de desconto. Em seguida, calcule o valor do desconto e o valor final a pagar.

Fórmulas: `desconto = valor * percentual / 100` e `valor_final = valor - desconto`
