# Exercício 09 — Controle de Estoque

**Aula 3 — Operadores matemáticos, lógicos e relacionais** · Operadores Relacionais

## Enunciado

Leia a quantidade em estoque de um produto. Se a quantidade for menor ou igual a 10, exiba "Reposição necessária"; caso contrário, exiba "Estoque suficiente".
