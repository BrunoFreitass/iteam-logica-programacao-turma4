# Exercício 01 — Cadastro de Notas

**Aula 6 — Vetores e Prática de Programação** · Vetores

## Enunciado

Crie um algoritmo que declare um vetor para armazenar 5 notas, solicite ao usuário que informe cada nota e, ao final, exiba todas as notas cadastradas na ordem em que foram informadas e também em ordem decrescente.

## Dica

Primeiro faça um laço para ler as notas e guardar no vetor; depois faça um laço para exibir as notas. Para a ordem decrescente, compare cada posição com todas as posições que vêm depois dela: use dois laços — o laço externo escolhe a posição atual e o laço interno procura um valor maior nas posições seguintes.
