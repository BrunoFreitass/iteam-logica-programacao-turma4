# Exercício 12 — Escolha do Menu

**Aula 5 — Estruturas de Repetição** · Estrutura REPITA

## Enunciado

Exiba o menu:

1. Novo cadastro
2. Consultar
3. Sair

Leia a opção escolhida até que o usuário informe uma opção válida (1, 2 ou 3). Depois, informe qual opção foi escolhida.
