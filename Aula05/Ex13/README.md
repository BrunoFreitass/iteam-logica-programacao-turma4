# Exercício 13 — Número Positivo

**Aula 5 — Estruturas de Repetição** · Estrutura REPITA

## Enunciado

Solicite ao usuário um número inteiro e repita a leitura até que seja informado um número maior que zero. Depois, exiba o número digitado.
