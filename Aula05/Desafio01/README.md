# Desafio 01 — Sistema de Vendas

**Aula 5 — Estruturas de Repetição** · Desafio integrador

## Enunciado

Crie um algoritmo que registre as vendas do dia de uma loja. Solicite o nome do vendedor, pergunte quantas vendas serão registradas e calcule o total vendido.

- Utilize **PARA** para ler o valor de cada venda.
- Caso alguma venda seja menor ou igual a zero, utilize **REPITA** para solicitar um novo valor válido.
- Ao final, exiba: nome do vendedor, quantidade de vendas, valor total vendido e valor médio das vendas.
- Pergunte se deseja iniciar um novo registro (S/N). Enquanto a resposta for S, todo o processo deve ser repetido — use **ENQUANTO**.

## Dica

Este desafio usa as três estruturas de repetição juntas. Lembre-se: ENQUANTO testa antes e pode não executar nenhuma vez; REPITA testa depois e executa ao menos uma vez; PARA é para quando o número de repetições já é conhecido.
