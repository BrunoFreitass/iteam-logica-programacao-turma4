# Projeto Final — Relatório de Produtividade da Equipe

**Aula 7 — Introdução a Python e Projeto Final** · Atividade avaliativa

## Enunciado

Crie um programa que gere um relatório de produtividade da equipe. O programa deve receber as horas trabalhadas por um grupo de funcionários (armazenadas em uma lista) e, para cada um, calcular as horas extras acima da jornada de 8 horas e classificar sua produtividade (abaixo, dentro ou acima do esperado). Ao final, deve exibir a média de horas da equipe e um relatório com o resultado de cada funcionário.

**Critérios avaliados**

| Critério | Peso |
|---|---|
| Funciona corretamente | 40% |
| Usa lista e repetição | 30% |
| Usa seleção (SE/SENÃO ou if/elif/else) | 20% |
| Código organizado e comentado | 10% |

## Dica

Teste com pelo menos 5 funcionários e horas variadas, incluindo casos de hora extra. A consulta à apostila é permitida — o objetivo é aplicar a lógica, não decorar sintaxe.

## O que entregar nesta pasta

- `algoritmo.alg` **ou** `algoritmo.py`

A entrega em Portugol (`.alg`) é a preferida; a versão em Python é opcional para quem quiser praticar a sintaxe nova.
